# Indian Stock Market Analysis | NSE Index Study

## About the Project

This is a personal finance research project in which I analysed seven NSE indices using Microsoft Excel.

The objective was to understand how different market segments performed during a selected rebound period and how their returns compared with volatility and drawdowns over a wider period.

## Indices Covered

- Nifty 50
- Nifty Midcap 100
- Nifty Smallcap 100
- Nifty Bank
- Nifty IT
- Nifty FMCG
- Nifty Auto

## What I Analysed

- Index returns over a selected period
- Relative performance using a rebased index level of 100
- Rolling volatility
- Drawdowns from previous peaks
- Differences between short-term and three-month performance

## Tools and Skills

- Microsoft Excel
- Data cleaning and organisation
- Return calculations
- INDEX/MATCH and SUMIFS
- Standard deviation and volatility
- Drawdown analysis
- Data visualisation and interpretation

## Key Learning

This project helped me understand why market performance should be examined across multiple indices, periods, and risk measures rather than relying on a single return figure.

It also highlighted a limitation of index-level analysis: individual-stock data is needed to test how broadly a recovery is being shared across the market.
